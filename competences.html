Conception et gestion de projet

  • Analyse du besoin : vision produit, personas, parcours utilisateurs – Sirene.
  • Découpage en versions : story mapping, User Stories, MVP – Sirene, SpoolBox.
  • Rôle de Product Owner : définir un produit, le présenter et le faire valider par l'équipe – Sirene.
  • Méthode agile (Scrum) : sprints, points quotidiens, estimation en planning poker, suivi de l'avancement, burndown chart – SpoolBox.
  • Qualité du code : revues de code par Pull Request, conventions de nommage de l'équipe, cahiers de tests de non-régression.
  • Mise en production : environnements de développement, recette, préproduction et production, procédures de déploiement écrites.
  • Recueil des retours utilisateurs : échanges avec les équipes de l'atelier, présentation de l'application aux nouveaux services.
  • Documentation : spécifications fonctionnelles et techniques, manuel d'utilisation, documentation de reprise d'un projet.
